# Solar Company Website

Website for a solar company, hosted free on GitHub Pages.

## Stack
Plain HTML + CSS. No framework, no build step. Add JS only when a feature needs it.

## Structure
- `index.html` — the site
- `style.css` — styles
- `images/` — photos and logos

## Hosting (GitHub Pages)
1. Push this folder to the GitHub repo `websiteproject`.
2. Repo → Settings → Pages → Source: `main` branch, root folder.
3. Live at `https://<username>.github.io/<repo>/`.
4. Custom domain later: add it under Settings → Pages.
